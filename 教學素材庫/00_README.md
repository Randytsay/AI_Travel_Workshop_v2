## 📋 Google Sheets 匯入方式

1. 開啟 Google Sheets → 新建空白試算表
2. 點「資料」→「從分隔符號分隔的檔案匯入」
3. 選擇以下對應的 `.tsv` 檔案
4. 匯入位置：各分頁（先建立分頁再匯入）

## 🎯 設計原則

每 10-15 分鐘必須有一次「笑、哇、原來、學到」循環：

```
[笑 🔥] 1-2min  → 破冰暖場，Hold 注意力
[哇 ✨] 2-3min  → Live Demo炫技，讓學員眼睛發亮
[原來 💡] 2-3min → 觀念翻轉，給「為什麼」
[學到 📝] 5-8min → 動手做，當場有產出
```
